about=QuickBDOT is a QGIS plugin for downloading, selecting, exporting and visualizing Polish BDOT10k topographic data. It supports the current map extent, polygon layer geometry and interactive county selection. Data can be exported to GeoPackage or Shapefile with optional BDOT10k symbology and labels. The plugin is intended for data covering Poland and does not require external Python packages.
